Social card

1200×630, drawn from topolang SHADE on seed 20260801 — the same mode, palette and seed as the homepage hero. With no query string this is the site card; save it to the repository root as og.png.

For a per-article card, pass the article’s own details. image and focus are optional — with no image the field fills the panel, so an article without a picture still gets a card:

?title=The%20GM%E2%80%99s%20Assistant&meta=Field%20Note%20%C2%B7%202,740%20words
?title=…&image=/images/bookshelf.jpeg&focus=50,30

focus is the crop centre as two percentages — the canvas equivalent of --vd-hero-focus. Serve the repository and use a path: a cross-origin image taints the canvas and toDataURL then throws, which looks exactly like a broken Save button.
