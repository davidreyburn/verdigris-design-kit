Prose and primitives

Body copy sits in .vd-prose, which caps the measure. An inline link is underlined — that is not decoration. It is the channel that separates a link from a success message, since both use the same hue, and colour alone measured 1.51:1 against body text where 3:1 is required.

Emphasis and italics behave normally. A marginal note1 uses the editorial colour — patina teal, the one this system is named for.
